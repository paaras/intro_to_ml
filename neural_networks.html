Neural networks

Every model so far has had its own idea of what a boundary should look like. Linear and logistic regression draw straight lines, KNN follows the nearest points, and decision trees draw boxes.

A neural network is built from lots of small pieces that each do something very simple. Together, they can learn almost any shape.

A neuron in your brain

Your brain has about 86 billion nerve cells called neurons, each connected to thousands of others.

A neuron collects signals from the neurons it's connected to. Some connections are strong and some are weak, so some signals count for more than others.

If the signals add up to enough, the neuron fires. It sends its own signal along its axon, a long branch that reaches the next neurons.

If they don't add up to enough, it stays quiet. A neuron is either firing or it isn't.

When you learn something, some of these connections get stronger and others get weaker.

Birds and planes

The first flying machines copied birds, flapping wings and all, and none of them worked.

Planes only flew once engineers kept the useful part, a curved wing that creates lift, and designed the rest their own way. Now a plane can carry 300 people across an ocean, while a bird can land on a branch and fly all day on a few seeds.

Neural networks are like planes. They borrow a single idea from the brain: simple units joined by connections that get stronger or weaker. The rest is math, and real neurons are much more complicated.

An artificial neuron

A neuron multiplies each input by a weight, adds them up with a bias, and passes the total through an activation function

An artificial neuron uses the same idea with numbers.

Each input is multiplied by a weight, which says how strong that connection is. A big weight means the input counts a lot. A negative weight pushes the other way.

The neuron adds these up, plus an extra number called the bias. We call the total z.

Then z goes through an activation function, which decides what the neuron sends on. This neuron sends 1 if z is above 0, and 0 if it isn't.

Flip the inputs and move the weights to see how z and the output change.

You already know a neuron

A neuron with a single input and no activation function works out z = w·x + b.

That's y = mx + b, the same line as linear regression. The weight is the slope and the bias is the intercept.

With a sigmoid as the activation function, the line gets squashed into an S between 0 and 1. That's logistic regression, shown here on hours studied and whether each student passed an exam.

So you've already used single neurons. What's new is connecting lots of them together.

Activation functions

The activation function takes a neuron's total z and decides what to send on. These are the three you'll see most.

Step is the closest to a real neuron, since it's either on or off. But it's flat almost everywhere, so a small change to a weight usually changes nothing. That makes it very hard to learn with.

Sigmoid is a smooth version of the step. A small change in z always makes a small change in the output.

ReLU keeps positive numbers and turns negative numbers into 0. It's simple and fast, so it's the most common choice inside networks. It's also the default in scikit-learn.

Truth tables

A logic gate takes inputs that are each 0 or 1, and gives back a 0 or 1.

Its truth table lists the output for every combination of inputs. With two inputs there are only four rows.

AND outputs 1 only when both inputs are 1.

OR outputs 1 when either input is 1.

XOR, short for exclusive or, outputs 1 when the two inputs are different.

Next we'll try to get neurons to produce these patterns.

A neuron that does AND

Let's see if a single neuron can do AND.

Each dot is a row of the truth table. The filled dots are the rows that should output 1.

The neuron fires on the shaded side of the line, where w₁x₁ + w₂x₂ + b is above 0. The weights turn the line, and the bias slides it.

Find weights that get all four rows right, then switch to OR. It's the same neuron with different weights.

Something a single neuron can't do

XOR is different. The two dots that should be 1 are in opposite corners.

No straight line can separate them from the other two, so no weights will get all four rows right.

In 1969, a famous book by Marvin Minsky and Seymour Papert pointed out limits like this, and interest in neural networks dropped off for years. The fix turned out to be using more than a single neuron.

Layers

The neurons in a network are arranged in layers.

The input layer is the features. The hidden layers do the work in the middle. The output layer gives the prediction.

Every neuron connects to every neuron in the next layer. Each connection has a weight, and each neuron has a bias. Together these are the network's parameters, and they're what it learns.

Making a prediction means passing the inputs through the network layer by layer. This is called a forward pass.

A network with lots of hidden layers is called deep, which is where deep learning gets its name. The parameters add up fast. A network that reads 28 by 28 pixel images of handwritten digits, with two hidden layers of 128 neurons, has 118,282 of them.

Nonlinearity

Real data is rarely a straight line. These dots show how busy a café is through the day, with a rush at breakfast and a bigger rush at lunch.

Without activation functions, a network can only draw a straight line, however many layers it has. That's just linear regression, which you could solve with a formula.

The activation function is what lets a network bend to fit curves like this. This is called nonlinearity, and it's what makes neural networks so powerful.

The network finds its own features

This is the position of 90 phones around a wifi router. The blue phones connected, and the others were too far away. To separate them with an SVM, you'd have to add x² + y² by hand or use a kernel.

A network does this on its own. Each hidden neuron draws a line, shown dashed, and the output neuron combines the lines into a shape.

A single hidden neuron gives a line. Two give a strip, three give a triangle, and four or more get close to a circle.

Nobody told the network about the distance from the router. It found its own features in the data, which is the biggest strength of neural networks.

Learning means walking downhill

A network starts with random weights, which give terrible predictions. Then it improves them a little at a time.

To do that, it needs to measure how wrong it is. This is called the loss, and lower is better, like the mean squared error from linear regression.

Linear regression had a formula that jumps straight to the best line. Networks don't, so they have to search.

Picture the loss as a hill, with the network standing on it in thick fog. It can't see the bottom, but it can feel which way the ground slopes. So it takes a step downhill and repeats.

This is called gradient descent, and the slope is called the gradient. This network has a single weight, so you can see the whole hill. Click the curve to start somewhere else.

How big a step?

Each step moves the weight by the slope times a number called the learning rate.

Steep ground gives big steps and flat ground gives small steps, so the steps shrink near the bottom.

If the learning rate is too small, training takes forever. If it's too big, each step overshoots the bottom, and the loss bounces around or shoots off.

Try a few learning rates and see where 20 steps get you. Finding a good value usually takes some trial and error.

Which way should each weight move?

A real network has thousands of weights, so its hill has thousands of directions.

For each weight it asks: if this weight goes up a little, does the loss go up or down, and by how much? That answer is the weight's slope.

Blue means increasing the weight lowers the loss, and red means it raises it. Thicker means a bigger effect. Each step moves every weight a little downhill at the same time.

Checking each weight separately would be slow, so networks use backpropagation to get every slope in a single pass. It starts from the error at the output and works backwards, figuring out how much each connection added to the mistake.

This network sees a single example and should output 1. Take a few steps and watch the loss go down.

This is also why the step function is hard to learn with. Nudging a weight almost never changes a step neuron's output, so every slope is 0 and nothing points downhill.

Stochastic gradient descent

To get the exact slope, a network has to look at every training example. With a million examples, each step takes a million predictions.

Stochastic gradient descent, or SGD, works out each slope from a small random batch of examples instead. The slope is a little off each time, so the path wobbles. But the steps are cheap, so it can take many more of them.

Here a neuron with two weights is fitting a line to 200 points. The loss is lowest in the middle of the rings.

Both methods get 2,000 examples. Plain gradient descent spends them on 10 careful steps, while SGD with batches of 10 spends them on 200 quick steps.

A full pass through the training data is called an epoch, and networks usually train for many epochs

Neural networks overfit too

Learning almost any shape is also a risk. With enough neurons, a network can bend around every training point, including the odd few that don't fit the pattern.

Here a big network, with two hidden layers of 32 neurons, is learning to tell lemons from oranges by their width and height. It trains on the filled fruits and is tested on the hollow ones. Drag the slider to move through training.

At first both losses go down. Then the test loss starts climbing while the training loss keeps falling. The network has stopped learning the pattern and started memorizing.

A common fix is early stopping. You hold back some training data, check its loss as you train, and stop once it stops improving. A smaller network or more data also help.

Learning from a useless feature

A network learns whatever helps on the training data, with no idea which patterns make sense. If a useless feature happens to line up with the answer, the network will use it.

In a well-known experiment, researchers trained a model to tell wolves from huskies using photos where the wolves were almost always in snow. The model learned to look for snow, not wolves.

Here each photo has the dog's weight, its snout length and whether there's snow. In this collection, 90% of the wolves are in snow. Try training with and without the snow feature.

No score will warn you about this. You have to think about whether each feature makes sense, like dropping a name column before training.

When to use a neural network

Neural networks do best with lots of data and patterns too complicated to describe by hand, like faces, speech or text. They find their own features, so you don't have to.

They also have downsides. They need a lot of data and computing power, and they have more settings to tune.

They're also very hard to explain. A decision tree can print its questions, but a network is thousands of numbers.

For a small table of data, a simpler model often does just as well. Decide whether a neural network is a good fit for each of these.

Neural networks in scikit-learn

scikit-learn's neural network is called MLPClassifier. MLP stands for multi-layer perceptron, an older name for this kind of network.

We'll use the wifi data from earlier. It has the position of 90 phones and whether each one connected to the router.

hidden_layer_sizes sets the hidden layers. (8,) means a single hidden layer with 8 neurons, and (16, 16) means two hidden layers with 16 each.

max_iter is the most epochs it will train for. The default is 200, which often isn't enough. Try changing 2000 to 200 and see what happens to the score.

The starting weights are random, so random_state keeps the results the same each run. Like KNN and SVMs, networks also need scaled features.

The F1 score

Precision is the share of predicted positives that were right.

Recall is the share of real positives that were found.

It's handy to combine them into a single score, but a plain average doesn't work well. Say 20 out of 100 patients are sick. A model that flags just a single patient as sick, and gets it right, has 100% precision but only 5% recall. The average is 52.5%, even though the model misses almost every sick patient.

The F1 score is a different kind of average that gets pulled down by whichever is lower:

F1 = 2 × precision × recall / (precision + recall)

It's only high when both are high, so it's a good score when the positive class is rare.

F1 in scikit-learn

f1_score works like accuracy_score. You give it the real answers first and the predictions second.
